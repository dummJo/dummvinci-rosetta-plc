## Keputusan yang diambil (dan alasannya)
- Allen-Bradley **tidak** dibuat. Logix bukan CODESYS; butuh emitter L5X
  sendiri (TONR/CTUD/OSRI, semua tag retentive), dan CLAUDE.md mewajibkan
  sampel + test lebih dulu. Dicatat sebagai `emit-l5x-rockwell` (false).
- Ekspektasi test lama `PV := D279` diubah jadi `PV := INT_TO_WORD(D279)`
  untuk target CODESYS (CTU.PV di library Standard = WORD). Bentuk INT tetap
  diuji di target generic.
- H2 tetap di-flag walau first-scan flag sekarang di-drive: di CODESYS flag
  tidak re-arm saat STOP→RUN tanpa reset (beda dengan M9038).
- Timestamp default build tetap (2000-01-01) agar reproducible;
  `timestamp`/`SOURCE_DATE_EPOCH` untuk stempel asli.
- Library CODESYS tidak bisa "diinstall" dari repo ini. Yang disediakan:
  manifest per target + key `libraries` di config untuk pin nama/versi situs.
